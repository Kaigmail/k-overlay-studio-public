# 默认编排偏好

> 本文件覆盖同目录 `我的偏好.default.md` 的同名条目;没写到的条目按默认表办。
> 定位第一条:专业可信优先于好看——见下方「数据可信」。

## 画幅与安全区(硬约束)

| 条目 | 取值 | 说明 |
|---|---|---|
| 默认画幅 | **9:16**(`aspect: "9:16"`) | 只有明说做横屏时才用 16:9 |
| 安全区 | **y 268–1483；x 59–1017，从 y=769 起右界为 x=887**（1080×1920） | 关键文字、数字和图表要让开右侧按钮与底部文案 |
| 人脸带 | **y 712–962** | 普通卡避开人脸；focus-card 自带人物框和要点 |
| 帧率 | 竖屏 **30fps**、横屏 29.97fps | 导出脚本已按 aspect 自动切换 |

## 落位(竖屏)

| position | 落位 |
|---|---|
| left / top / top-left / top-right | **上带**（x 79–997、y 352–690） |
| right / bottom / center | **下带**（x 79–867、y 1010–1350），字幕在 y 1370–1460 |
| 章节条 | 顶部通栏（x 79–997、y 284–338），全程常驻 |

横屏落位照原作,不另定。

## 颜色(色义 A · 2026-11-17 拍板)

| accent | 含义 | 色值(暗底) |
|---|---|---|
| `blue` 数据蓝 | 数据 / 中性陈述 / 里程碑 | #5fa0fa |
| `alert` 否定红 | 否定 / 风险 / 警示 | #e88686 |
| `orange` 转变橙 | 转变 / 转折 / 优先级 | #f0a24f |
| `green` 达成绿 | 达成 / 正向 / 已验证 | #6fd08c |

- **涨跌绝不用颜色表达**:内容横跨 A 股/港股与美股,红绿在两个市场含义相反,必然误导一半观众。涨跌必须用文字/符号表达(+12% / −3% / ▲ / ▼ / 涨 / 跌),颜色只做上表四种语义。
- 一段一色、同段 accent 一致;整期主色默认 `blue`,只有语义需要时才换色。

## 数据可信(硬约束)

- 卡面出现的数字、涨跌幅、排名、比例,**必须来自口播稿原文或可核查来源,禁止编造**;稿里没有的数字,宁可不用数据类卡。
- 引语必须逐字来自稿件,不得把转述写成引语。

## 常驻层

| 条目 | 取值 | 说明 |
|---|---|---|
| `chapter-bar` 章节条 | **默认开** | 3 分钟以上必开;章节按内容结构切 |
| `caption-track` 字幕条 | **默认关** | 字幕在剪映里另加,开字幕条会双字幕;只有明说要烧录字幕时才开 |

## 文字量

- 卡面文字**必须短于口播原句**(硬约束,同默认表)。
- 标题一句话说完、能短则短;条目只放关键词,不放整句(字数上限暂不定量,先定性执行,三五期后按成片复盘再定数)。

## 字体

| 条目 | 取值 |
|---|---|
| 编排 font 字段 | **`"Noto Sans SC"`**(思源黑体) |
| 代码默认栈 | 已定版思源优先:`Noto Sans SC → Source Han Sans SC → PingFang SC → Hiragino Sans GB → Microsoft YaHei` |
| 英文 kicker / 数字 | 等宽栈已定版 `JetBrains Mono` 优先 |

本地机器需装思源黑体(免费),没装时自动回退苹方/雅黑,不影响出片。

## 密度与节奏

- 沿用默认表:8–12 张/分钟、新动作间隔 2–4 秒、同屏 ≤2 张、同屏进场错开 ≥0.5s。
- 短卡 3–5s、内容卡 5–12s 跟讲述走。
